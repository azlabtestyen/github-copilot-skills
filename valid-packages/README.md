# Valid Microsoft Skill Packages

共 183 個獨立 `.skill` 封裝。每個獨立檔案的 ZIP 根目錄直接包含 `SKILL.md`，且 `SKILL.md` 含有 YAML frontmatter 的 `name` 與 `description`。

- `individual-skills/`：逐項獨立 `.skill` 檔案。
- `microsoft-skills-collection.zip`：集合封裝；其根目錄也直接包含 `SKILL.md`，並在 `skills/` 中收納全部獨立封裝。
- `manifest.json`：完整清單與 SHA-256。
