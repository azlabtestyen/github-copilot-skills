# Microsoft GitHub Copilot Skills

本 repository 只保存 Microsoft 生態相關的官方 GitHub Copilot Agent Skills，來源為 [github/awesome-copilot](https://github.com/github/awesome-copilot)。

請先閱讀 `MICROSOFT_SKILLS.md` 查看分類與完整索引，再從 `microsoft-skills/packages/` 或 `microsoft-skills/archives/` 取用技能。

分類包括：Azure 基礎設施、.NET/ASP.NET、PowerShell/Windows、Visual Studio/VS Code、Microsoft 365、GitHub Copilot/Actions，以及 Microsoft AI/Data。

技能可能包含腳本或命令，使用前請審查對應的 `SKILL.md`；不要對未審查技能預先允許 shell/bash。
